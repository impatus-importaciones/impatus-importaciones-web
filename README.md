# Impatus Importaciones

Portfolio empresarial estático para Impatus Importaciones S.L., empresa importadora de frutas del Alto Valle del Río Negro.

## Ejecutar localmente

No requiere instalación ni dependencias. Abrí `index.html` en el navegador o usá cualquier servidor estático local.

Ejemplo con Python:

```bash
python -m http.server 8000
```

Después visitá `http://localhost:8000`.

## Publicar

El proyecto se puede desplegar directamente en GitHub Pages, Netlify, Vercel, Cloudflare Pages o cualquier hosting estático. Reemplazá los datos de contacto provisionales, los enlaces legales y las imágenes antes de publicar.
